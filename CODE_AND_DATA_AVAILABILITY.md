# Code and data availability

The study-level records and reproducibility code supporting this review are available in the public GitHub repository:

https://github.com/tranducle/Posthoc-xAI

The repository contains the full-text screening record, 84-study extraction matrix, evidence-maturity codebook and classifications, coding-reliability record, canonical study-level dataset, machine-readable data underlying the quantitative tables and figures, and scripts used to recompute the reported counts, percentages, sensitivity analyses, and reliability statistics.

Publisher full texts and the original Scopus, Web of Science, and IEEE Xplore exports are not redistributed because they are subject to publisher or database access terms. The repository provides identifiers, DOI status, source metadata, screening decisions, extraction records, and derived coding needed to audit the review without redistributing those restricted source files.

No standalone software application was developed for the review. The public scripts reproduce the numerical synthesis and can regenerate local versions of the data-driven figures from the released records.
